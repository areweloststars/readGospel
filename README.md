# readGospel
성령으로거듭나세요

마태복음·마가복음·누가복음을 하루 한 장씩 그림과 함께 읽는 정적 웹 페이지입니다.
`index.html`을 브라우저로 열거나 아무 정적 호스팅(GitHub Pages 등)에 이 폴더를 그대로 올리면 됩니다.

- 준비된 장: 마태복음 1–28장, 마가복음 1–16장, 누가복음 1–14장 (요한복음은 준비 중)
- 성경 인용: 모두 헬라어 원문 SBL Greek New Testament(SBLGNT, © 2010 Society of Biblical Literature·Logos Bible Software, CC BY 4.0)를 쉬운 우리말로 옮긴 ‘쉬운 번역’입니다. 공식 번역이 아니며, 다른 한국어 번역 성경의 본문은 싣지 않았습니다.
- 그림: 저작권이 만료된 퍼블릭 도메인 작품(대부분 제임스 티소의 〈예수의 생애〉 연작, 1886–94)입니다. 그 밖의 출처는 페이지 맨 아래 ‘출처’에 있습니다.

## 구성

- `index.html` — 페이지 전체(스타일과 스크립트 포함)
- `data/meta.js` — 책 목록, 장 제목, 그림 출처
- `data/{mat,mrk,luk}/NN.js` — 장별 요점과 쉬운 번역 본문
- `images/` — 그림 파일
